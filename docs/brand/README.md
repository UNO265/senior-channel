# 브랜드 (초안, 사용자 확정 전)

| 파일 | 크기 | 용도 |
|---|---|---|
| `logo.png` | 800×800 | 프로필 사진 — 두 집 + 채널명 |
| `logo-icon.png` | 800×800 | 프로필 사진 — 두 집만(작게 보일 때 더 선명) |
| `banner.png` | 2560×1440 | 채널 배너. 글자는 모든 기기 안전 영역(가운데 1546×423) 안, 마을은 데스크톱에서만 보이는 양옆 |

- 콘셉트: 나란히 선 두 집(김 씨와 이 씨, 이웃), 불 켜진 창(따뜻함).
- 색: 남색 `#1F3A5F`(신뢰), 청록 `#3F7A8C`, 주황 `#F08A3C`(불 켜진 창), 크림 `#FBF5EA`, 모래 `#EADFCB`.
- 글꼴: 고운바탕 Bold(채널명), 고운돋움(부제). 둘 다 SIL OFL — 상업 이용·이미지 사용 가능.
- 다시 만들기: `python make_brand.py` (cairosvg, 글꼴 설치 필요). 색·문구는 이 파일에서 고친다.
