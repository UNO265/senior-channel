# 03 VISUAL & AUDIO — 음성·화면·자막·소리·렌더링

> 00 CORE가 우선한다.

## V1. 원칙 【미정】

화면이 내레이션과 어떤 관계인가(복사하지 않는다 / 보완한다 등).

## V2. 화면 유형과 스타일 【미정】

정할 것: 일러스트·인포그래픽·실사·자료 화면의 비율, 그림체, 색.

## V3. 자막과 화면 글자 【미정】

정할 것: 자막 유무, 글자 크기·굵기·대비(시니어 가독성), 한 화면 최대 글자 수, 표시 시간.

## V4. 움직임과 전환 【미정】

정할 것: 컷 길이, 전환 속도, 피해야 할 효과(깜빡임·빠른 줌).

## V5. 내레이션 【일부 확정 2026-10-05】

- **엔진**: Qwen3-TTS(`Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, Apache-2.0, 무료·상업 이용 가능) 【확정 2026-10-05】
- **내레이터**: 기본 화자 **Sohee**(따뜻한 한국어 여성) + 지시 "차분하고 따뜻하게, 조금 천천히 또박또박 말해 주세요." 【확정 2026-10-05】
- 생성: `tools/tts_qwen.py`. 이 클라우드 환경(CPU)에서는 실제 길이의 약 6배 시간이 걸린다. GPU면 훨씬 빠르다. wav는 git에 넣지 않고 `audio/timings.json`만 올린다.
- 원고: 확정 대본 → `tools/tts_prep.py` → `tts/script.tsv`(숫자는 한글 읽기로 통일).
- 폐기: MeloTTS 한국어(2026-10-05 시험, "너무 기계음" — 사용자 판단).
- 롱폼 인물 목소리: 미정. 후보는 같은 모델의 목소리 설계(VoiceDesign)로 인물별 목소리를 만들어 고정하는 방식.

정할 것: 롱폼 인물 목소리, 크레디트 표기 여부.

## V6. BGM·효과음 【미정】

## V7. 자료·사용권 【미정】

정할 것: 실사·사진 사용 여부, 사용권 확인 방법, 로고·인물 처리.
