# 02 SCRIPT — 구성과 대본

> 00 CORE가 우선한다.

## S1. 형식 【미정】

정할 것: 대본 제출 형식, 문체(하십시오체/해요체), 문장 길이, 한자어·외래어 처리.

## S2. 전체 구성 【미정】

영상 한 편의 뼈대(도입 → 전개 → 정리)와 각 부분의 역할.

## S3. 첫 30초 【미정】

정할 것: 첫 문장의 유형(질문·장면·공감), 약속을 말하는 시점, 타이틀 위치.

## S4. 중간 보상 【미정】

몇 분마다 무엇(새 정보·정리·예시)을 주는가.

## S5. 시니어 듣기 리듬 【미정】

정할 것: 말하는 속도, 핵심을 반복해 정리하는 주기, 한 문장에 담는 정보 수.

## S6. 마지막과 엔딩 【미정】

정할 것: 요약 방식, 시청자에게 남기는 행동·선택지, 고정 엔딩(C8)과의 연결.
