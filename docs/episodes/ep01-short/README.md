# EP01 짧은 판 (약 5분) — 초안

> 상태: **제목·대본 초안, 사용자 확정 전**
> EP01(롱폼, 확정 대본)의 핵심만 5분으로 줄인 첫 업로드용 영상. 조사·숫자는 [EP01 research.md](../ep01/research.md)를 그대로 쓴다(F번호 동일, ☐ 항목은 업로드 전 1차 확인).
> 분량: 약 1,600~1,800자(공백 포함) — 00 C4(15,000자)의 예외. DECISIONS에 기록.

## 제목 후보

| # | 제목 | 메모 |
|---|---|---|
| S1 | 국민연금 냈더니 기초연금이 깎였다? 5분이면 계산돼요 | 추천. 질문 + 5분 약속 |
| S2 | 국민연금 낸 사람이 손해? 기초연금 감액, 5분 정리 | 손해 여부를 바로 묻는다 |
| S3 | 기초연금 깎인 84만 명, 나도 해당될까? | 숫자로 신뢰. F6 확인 필수 |

| 장 | 분량(자) | 내용 |
|---|---|---|
| 0 | 250 | 김 씨 한마디 + 두 통장(25만 7천 원 남짓 vs 34만 9,700원) + 약속 |
