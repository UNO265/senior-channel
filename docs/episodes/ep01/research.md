# EP01 리서치 — 국민연금 30년 낸 김 씨, 안 낸 옆집 이 씨보다 손해일까?

> 주제 확정: 2026-10-04 (후보 1번) / 제목 확정: 2026-10-04 (T1)
> 상태: **조사 중**. 아래 숫자는 웹 검색 결과로만 교차 확인했다. 이 작업 환경에서는 공식 사이트(복지부·국민연금공단·국회예산정책처·법령정보센터)에 접속할 수 없어 1차 원문을 직접 열어 보지 못했다. 대본 확정 전에 ✅ 표시가 없는 항목은 원문으로 확인한다.

## 1. 답 카드 (주제 게이트, 초안)

| 항목 | 내용 |
|---|---|
| 제목 질문 | 국민연금 30년 낸 김 씨, 안 낸 옆집 이 씨보다 손해일까? (확정) |
| 형식 | 예/아니오 + 숫자 |
| 1/3 지점의 답 | **아니에요.** 기초연금이 깎여도 두 연금을 합치면 김 씨가 매달 더 받아요. 깎이는 건 국민연금이 월 52만 4,550원을 넘을 때뿐이고, 깎여도 최대 절반까지예요. (2026년 기준) |
| 마지막의 더 정확한 답 | **깎이지만, 손해는 아니에요. 국민연금이 월 17만 4,850원을 넘는 한 김 씨의 합계는 언제나 이 씨보다 많아요(계산식상).** 김 씨(국민연금 월 80만 원 가정)는 기초연금이 약 9만 원 깎여도 둘을 합치면 월 약 105만 원이에요. 안 낸 이 씨는 기초연금 34만 9,700원이 전부예요. (※계산·가상 사례) |
| 시청자에게 남는 것 | 내 국민연금의 "A급여액"을 확인하는 곳과 방법. 내 기초연금이 깎일지 계산하는 법. |
| 이 채널에서만 줄 것 | ① 감액 계산식을 그림으로 풀기 ② 84만 명·804억 원이라는 결산 숫자 ③ "깎인다"와 "손해다"는 다르다는 결론 |

## 2. 사실 확인표

| # | 사실 | 값 | 출처(2차) | 1차 확인 |
|---|---|---|---|---|
| F1 | 2026년 기준연금액(단독, 월 최대) | 349,700원 (2025년 대비 물가 2.1% 반영) | 국민연금 온에어, 기초연금 2026 가이드 | ☐ 복지부 고시 |
| F2 | 국민연금 연계감액이 없는 기준 | 국민연금 급여 월 524,550원 이하 (기준연금액 150%) | 2026 감액기준 정리 글 다수 | ☐ 기초연금법 시행령 |
| F3 | 감액 계산식 | 기초연금 = (기준연금액 − ⅔ × A급여액) + 부가연금액, 기준연금액이 상한 | 찾기쉬운 생활법령(easylaw) 검색 요약 | ☐ 기초연금법 제5조 |
| F4 | 부가연금액(=최저 보장, 기준연금액 50%) | 174,850원 | 위와 같음 | ☐ |
| F5 | A급여액 문턱 | 262,270원 (계산값 262,275원 → 법정 단위 절사 추정) | 검색 요약 | ☐ 단위 처리 확인 |
| F6 | 2025년 말 연계감액 대상자 | 84만 2천 명 (2021년 38만 9천 명) | 국회예산정책처 「2025회계연도 결산 분석」 인용 보도(2026.8.23) | ☐ NABO 원문 |
| F7 | 감액액 | 804억 4,062만 원 (2021년 276억 1,574만 원, 2.9배) | 위와 같음 | ☐ |
| F8 | 2027 개편안(2026.9.1 복지부 발표)에 연계감액 변경 없음 | 유지 | 개편안 정리 글 | ☐ 복지부 보도자료 |
| F9 | 2027 부부감액 축소안 | 소득 하위 45% 부부 20% → 10% (단계 일정은 자료마다 다름) | 개편안 정리 글 | ☐ 국회 예산 통과 전, "안"이라고만 말한다 |

### ⚠ 확인이 꼭 필요한 것

- **F7의 기간 문제**: 보도는 "1인당 연간 감액 약 9만 6천 원"이라고 했다. 그런데 804억 ÷ 84.2만 명 = 약 9만 5,500원이고, 이를 1년으로 나누면 월 8천 원이다. 계산식대로라면 감액 대상자의 감액액이 월 0~17만 원이므로, 804억은 **연간 총액이 아니라 특정 월(12월) 지급분**일 가능성이 있다. 헤드라인도 "2025년에만 800억"과 "4년간 804억"으로 엇갈린다. **NABO 원문을 확인하기 전에는 영상에서 1인당 금액을 말하지 않는다.**
- **F3·F5**: A급여액은 연금 통지서에 바로 나오지 않는 값이다. 시청자가 A급여액을 어디서 확인하는지(국민연금공단 조회 경로)를 1차로 확인해야 "남는 것"을 줄 수 있다.

## 3. 예시 계산 (※계산, 가상 사례)

- 김 씨: 국민연금 월 800,000원, A급여액 400,000원(가정)
  - 349,700 − ⅔ × 400,000 + 174,850 = **257,883원** → 감액 91,817원
  - 국민연금 + 기초연금 = 약 **1,057,883원**
- 이 씨: 국민연금 없음, 소득인정액 기준 충족 가정 → 기초연금 **349,700원**
- 주의: A급여액은 가입 기간·소득에 따라 달라서 실제 사례처럼 말하지 않는다. "예를 들어 A급여액이 40만 원이라면"으로 말한다.
