# EP01 구성 설계 v3 (초안) — 국민연금 30년 낸 김 씨, 안 낸 옆집 이 씨보다 손해일까?

> 상태: **사용자 확정 전 초안**. 확정되면 대본으로 넘어간다.
> v3 변경(2026-10-04): [벤치마크 메모](../../research/benchmark-script-structure.md)를 반영했다. 5막 구성, 감정 곡선, 장마다 여는 장면, 첫 10초 감정 훅, 귀로 듣는 계산, 통쾌한 결말.
> 분량: **15,000자 내외**(00 C4). 예상 길이 약 40~50분. 최종 음성으로 확인한다.
> 1/3 지점 = 약 5,000자. 제목 질문의 첫 답("아니에요")은 4장, 누적 5,000자 안에서 준다.
> 등장인물은 모두 가상이다. 1장에서 "이해를 돕기 위한 가상 사례"라고 밝힌다(00 C5). 인물은 가상이어도 제도·금액은 2026년 현행 기준.
> 숫자는 [research.md](research.md)의 F번호. ☐(1차 미확인)는 대본 확정 전에 확인한다. ※계산은 화면에 표시한다.

| 인물 | 설정 | 역할 |
|---|---|---|
| 김 씨 (70) | 30년 직장 생활, 국민연금 월 80만 원(A급여액 40만 원 가정) | 주인공. 억울함 → 깨달음 |
| 김 씨 아내 | 김 씨와 함께 통지서를 보는 사람 | 김 씨의 마음을 말로 끌어내는 대화 상대 |
| 이 씨 (70) | 옆집, 자영업, 국민연금 미가입. 기초연금 34만 9,700원 | 비교 대상. 악역이 아니다 |
| 이 씨 아들 (52) | 국민연금 납부를 그만둘까 고민 중 | 결말에서 50대 시청자의 자리 |
| 박 씨 부부 (72·70) | 둘 다 국민연금, 재산이 조금 있음 | 10장의 "다른 함정" 사례 |
| 동네 세 사람 | 국민연금 40만·80만·150만 원 | 6장 비교 계산 |

## 감정 곡선

```
억울함 ──► 안도 ──► 의문·분노 ──► 이해·경계 ──► 희망·통쾌
 1막        2막        3막            4막            5막
```

## 쓰는 규칙 (이 편)

- **귀로 듣기**: 화면을 안 봐도 이해되게 쓴다. 숫자는 한 문장에 하나만 쓰고, 큰 숫자는 "52만 원 남짓"처럼 말한 뒤 정확한 값은 화면에 둔다. 핵심 숫자는 막이 바뀔 때 한 번 더 말한다.
- **사연의 끈**: 모든 장을 인물의 장면으로 연다. 정보 설명은 인물의 질문에 대한 답으로 말한다.
- **이 씨는 악역이 아니다**: 국민연금을 안 낸 사정을 존중한다. 대립은 사람이 아니라 제도의 구조다.
- **감정은 숫자로 풀어 준다**: 억울함과 분노를 키우는 데서 멈추지 않는다. 장마다 확인된 숫자로 답을 준다(과장·공포 조장 금지, 00 C5).
- **중간 정리**: 세 번(4장·8장·13장). "지금까지 확인한 것" 세 줄이며, 같은 문장을 되풀이하지 않는다.
