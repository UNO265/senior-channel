# EP01·짧은 판 사실 확인 체크리스트 (휴대폰용)

> 짧은 판 업로드 전에 **1~7번**은 꼭 확인한다. 롱폼은 8~10번까지.
> 결과는 맞음 ✅ / 다름(실제 값 적기) ✏️ / 못 찾음 ❓ 로 적어서 알려 주면 대본·자료를 고친다.
