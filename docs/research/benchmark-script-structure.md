# 벤치마크: 시니어 롱폼 대본 구조 (2026-10-04 조사)

> 한계: 이 작업 환경에서는 유튜브 영상·자막과 분석 사이트(vling 등)에 접속할 수 없다. 아래는 **웹 검색 결과(제작법 블로그·강의·기사)에 나온 2차 정보**다. 실제 인기 영상의 대본을 확인한 것이 아니다. 제작법을 파는 쪽의 주장이 섞여 있어 과장됐을 수 있다.

## EP01 구성에 주는 시사점

1. B1: 첫 10초를 숫자보다 김 씨의 억울한 한마디로 시작한다.
2. B2: 감정 곡선을 설계한다. 억울함(0~3장) → 안도(4장) → 의문·분노(7장 제도의 역사) → 이해(8~11장) → 희망·행동(12~13장).
3. B5: 귀로만 들어도 이해되게 쓴다. 계산식(5장)은 화면 없이도 따라올 수 있게 숫자를 적게, 핵심 숫자는 다시 말한다.
4. 정보가 몰린 5~11장에서 사연의 끈이 끊기지 않게, 각 장을 김 씨·이웃의 장면으로 시작한다.
5. B4: 13장을 5막으로 묶어 리듬을 잡는다.
